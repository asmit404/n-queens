# N-Queens Solver

## Introduction

The N-Queens problem is a classic problem in computer science. The problem is to place N queens on an N x N chessboard so that no two queens are attacking each other. The problem is a generalization of the 8-Queens problem, which is to place 8 queens on an 8 x 8 chessboard so that no two queens are attacking each other.

## Usage

To use the N-Queens Solver, open the index.html file in a web browser. The N-Queens Solver will display the solution to the N-Queens problem for the given N. It displays the solution as a chessboard with the queens placed on the board, using a backtracking algorithm to find the solution.

## Algorithm

The N-Queens Solver uses a backtracking algorithm to find the solution to the N-Queens problem. The algorithm works by placing queens on the board one at a time, checking if the queen is attacking any other queens on the board. If the queen is not attacking any other queens, the algorithm places the next queen on the board. If the queen is attacking another queen, the algorithm backtracks and tries a different position for the queen.
